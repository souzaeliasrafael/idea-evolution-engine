# Idea Evolution Engine backend

FastAPI backend package for Idea Evolution Engine Phase 6, including project
persistence, independent per-agent provider/model routing, provider-neutral
Structurer, Builder, Researcher, Critic, and Judge agents, immutable idea versions,
deterministic scoring, hypotheses, traceable evidence, bounded orchestration,
explicit rounds/transitions, and agent-run auditing. Complete documentation is in
the repository-level `README.md` and provider setup is in `../PROVIDERS.md`.
